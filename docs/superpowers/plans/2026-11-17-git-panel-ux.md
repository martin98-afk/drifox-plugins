# Git 面板体验与性能实施计划

> 执行方式：用户已指定单人开发，当前会话逐项执行与自审，不分发子智能体；不自动提交、推送或发布。

**目标：** 将现有左侧 Git 面板升级为变更/历史分离、列表/文件树切换和增量刷新面板。

**架构：** 保留 cards.py 的 Git 操作、AI 与 Diff 对话框。新增 changes_view.py 承载 Qt 模型/视图文件列表，新增 task_runner.py 承载串行后台调度；卡片负责页面和数据快照，不将 QWidget 状态读取放到后台。

**技术栈：** Python、PyQt5、qfluentwidgets、stdlib unittest、git CLI。

## 2. 文件列表与文件树

文件：新增 `ui/changes_view.py`，测试 `tests/test_workflow.py`。

- [x] 基于 QStandardItemModel/QTreeView 创建暂存/工作区/冲突分组，使用 `Qt.UserRole` 存完整文件字典，目录节点无文件操作。
- [x] 列表以文件名为主、目录为副文本；树按路径建立目录，两个视图可切换，QSettings 记住模式。
- [x] 委托绘制状态与就地操作，避免 setIndexWidget；信号统一为 `(action, file_info)`，鼠标、Enter 和右键复用。
- [x] 相同状态元组直接返回，不清空模型；变化时保存选择、展开、滚动后恢复，覆盖新目录、文件删除和同路径双区状态。

## 3. 后台串行调度与读取基线

文件：新增 `ui/task_runner.py`，修改 `ui/cards.py`。

- [x] 所有卡片级 Git 任务统一提交调度器，线程池任务只处理捕获的值；回调在主线程分发，任务异常恢复按钮。
- [x] 同一时刻只执行一个卡片任务；刷新合并、写入按顺序排队；清理取消未开始任务并隔离过期回调，运行中的原生对象保活到结束。
- [x] 刷新捕获仓库、版本、页面、历史条数；变更页只查 status_v2，历史页按需查 log，分支和搁置改菜单请求。
