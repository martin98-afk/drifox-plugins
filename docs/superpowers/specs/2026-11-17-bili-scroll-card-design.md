# B站值班卡片视觉改造

## 已确认方向

采用精简工作台：顶部状态摘要，宽窗口日报与视频记录左右分栏，窄窗口上下排列，技术细节默认折叠。保留原有值班、刷新、打开数据目录、关闭能力，不新增业务功能。

## 页面结构

1. 顶部：标题、简短说明、固定短文案「跑一轮」主按钮、刷新、关闭。
2. 摘要：今日精选与配额、凭证状态、自动值班、自动评论。每项独立卡片；窄窗口四列变两列。凭证存在仅显示「已保存」，提示未校验有效性。
3. 主体：日报为主阅读区，使用 Markdown 排版；最近视频为次阅读区，分离标题、UP 主、日期、BV 号与处理结果。宽窗口按 3:2 排列，窄窗口上下排列。
4. 空态：日报、视频记录各自展示标题和一句操作指引，不再用裸文本占位。
5. 底部：运行反馈、数据目录入口、可展开环境检查。完整数据路径、依赖、工具注册与原始诊断保留在折叠区，最近判重数据不重复显示。

## 实现边界

- 仅修改 `plugins/bili-scroll/ui/cards.py`、插件 README，按需新增同插件 UI 辅助文件、专项测试。
- 使用现有 PyQt5 / qfluentwidgets；不引入 WebEngine 和新依赖。
- 主题优先读取宿主 context 的颜色与字体，深浅模式均有回退，支持 `refresh_style()`。
- 保留现有数据快照结构和采集逻辑，不改存储、MCP、调度、评论策略。
- 运行按钮加载中不膨胀宽度；加载与运行避免同一卡片重复启动 worker；轮结果显式交给 `_render_round`，不误走状态渲染。
- 日报链接仅允许系统浏览器打开 HTTP / HTTPS。

## 验收

- 宽 1100、窄 620 和更窄 460 像素下无横向溢出，空态和有内容均可读。
- 长标题、长路径、报错文本不撑坏布局；长列表在内容区域滚动。
- 凭证存在不展示为「登录有效」；环境诊断不打印重复视频字典。
- 深浅主题、折叠诊断、刷新、运行结果和关闭信号有测试证据。
- 使用独立 Qt 预览实例截图，不触发真实值班，不替用户发评论。
- 若同步到宿主开发插件副本，只同步本次 UI 文件及文档，且先核对其与源码差异，不覆盖其他变更。

## 自审

无新业务能力、无配置迁移、无后端数据契约变化；所有状态取自现有快照，效果稿中的示例数据不进入生产。
