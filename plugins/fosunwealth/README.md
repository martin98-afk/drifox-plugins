# 星财富AI

从你关心的问题出发，获得更清晰的金融洞察。

## 启用

设置 → MCP 连接器 → 找到本插件 → 启用。工具名前缀 `mcp__fosunwealth__`。

## 认证

无需预置密钥，启用后直连。星财富 AI（复星衡吉）金融洞察服务。

## 上游

- 服务方端点: `https://aiapi.fosunhanig.com/ai-fin-agent/mcp`
- 传输: streamable HTTP
- 来源: WorkBuddy 连接器市场（connector-plugins 整包）

## 示例

- 帮我看看腾讯现在怎么样
- 对比苹果和微软的基本面要点
- 最近有什么值得关注的市场新闻
