# Slack

跨频道和私信读写搜索 Slack 消息。用自然语言创建管理 Canvas 文档、定时发送消息、添加表情回应、查找用户信息。

## 启用

设置 → MCP 连接器 → 找到本插件 → 启用。工具名前缀 `mcp__slack-mcp__`。

## 认证

OAuth 授权。Slack 官方 MCP 走 OAuth 授权，首次启用时按提示在浏览器完成工作区授权。

## 上游

- 服务方端点: `https://mcp.slack.com/mcp`
- 传输: streamable HTTP
- 来源: WorkBuddy 连接器市场（connector-plugins 整包）

## 示例

- 帮我把所有公开频道里最近一周提到【上线】或【事故】的消息找出来，按频道和时间整理，把每条消息的讨论串也展开看看有没有结论
- 在本周内每天早上 9 点往 #团队公告 发一条站会提醒，内容包含日期和让每个人同步进度的模板，周一到周五都发
- 查一下 @张伟 的个人资料和最近两周在哪些频道说过话，他主要关注什么话题，帮我判断要不要拉他进新项目群
- 把上次需求评审的讨论串整理成一份 Canvas，结构包含：背景、决策要点、待办事项（带负责人和截止日期）、相关链接，然后发到 #产品 频道让大家补充
