# webdav-backup

将 DriFox 数据全量备份到任意 WebDAV 网盘（坚果云、Nextcloud 等），支持定时自动备份、AES-256 加密、历史版本管理与一键恢复。

## 功能

- **范围可选**：备份卡右栏按类勾选备份内容（会话/助手数据/插件配置/已装插件/技能/工作流/归档/工作区），「额外包含」支持补充清单外目录（逗号分隔）；数据目录根部散文件（数据库/配置）始终包含。连接配置（服务器/账号/密码）在 设置 → 插件 → WebDAV 备份
- **全量备份**：自动排除日志、缓存、锁文件、恢复现场目录（`restore/`）与超过 200MB 的单文件；备份前对数据目录根部 `*.db` 执行 WAL checkpoint，并用 SQLite backup API 生成一致性快照入包（避免运行中被锁导致库文件漏备）；个别文件读取失败会重试后记入未入包清单，在备份结果与卡片摘要中警告
- **定时备份**：距上次成功备份超过设定间隔（默认 24 小时）自动执行，无需打开卡片
- **可选加密**：设置加密密码后备份包经 AES-256-GCM 加密（PBKDF2-SHA256 派生密钥，480k 轮），扩展名 `.dvp`；留空则为普通 zip，可用任意解压工具打开
- **版本管理**：远端保留最近 N 份（默认 10），超出自动清理最旧
- **一键恢复**：左侧列表选择恢复；覆盖前在数据目录下的 `restore/rollback-<时间戳>/` 留存回滚副本。被 DriFox 占用的文件（运行中的会话库等）自动暂存到 `restore/pending-<时间戳>/` 并生成 `restore/restore-<时间戳>.bat`，同时弹窗给出编号步骤、自动用资源管理器定位该脚本，完全退出 DriFox 后双击脚本即完成剩余覆盖

## 配置

设置 → 插件 → WebDAV 备份：

| 字段 | 说明 |
|------|------|
| 服务器地址 | 坚果云：`https://dav.jianguoyun.com/dav/`；Nextcloud：`https://你的域名/remote.php/dav/files/你的用户名/` |
| 账号 | 坚果云填注册邮箱 |
| 密码 | 坚果云必须用「应用密码」，不能用登录密码（设置卡内有「应用密码怎么拿」外链，直达坚果云帮助中心图文步骤）；Nextcloud 填账号密码或应用专用密码 |
| 应用密码怎么拿 | 外链字段，点击在系统浏览器打开坚果云官方图文教程（仅坚果云用户需要） |
| 备份加密密码 | 留空不加密；设置后备份包加密上传，恢复时需同一密码 |

备份范围、立即备份、历史列表与恢复在 侧边栏 → WebDAV 备份 卡片内操作：左栏为云端备份列表（区域内滚动），右栏为备份范围勾选（勾选即存），操作按钮（立即备份 / 测试连接 / 刷新列表）在卡片顶部。

## 注意

- 备份在后台线程执行；数据目录根部 SQLite 库（如会话库）以 backup API 快照入包，即使 DriFox 运行中也能拿到一致性副本，并在备份前尽量合并 WAL 减小包体积。极少数快照与直读均失败的场景会在结果消息中警告，可在备份前关闭 DriFox 重试
- 恢复会覆盖本地数据；恢复现场统一放在 `<数据目录>/restore/`（`rollback-*` 旧文件副本、`pending-*` 待应用文件、`restore-*.bat` 完成脚本）。被占用的文件会两段式完成：恢复后弹窗给出步骤并自动定位脚本，完全退出 DriFox 后双击脚本，再重启 DriFox 生效
- `restore/` 目录不会被备份入包；确认恢复无误后可自行删除 `rollback-*` 与 `restore-*.bat`
- 坚果云免费版有流量与请求频率限制，备份间隔不宜低于 1 小时；上传流量超额时服务器返回 `403 TrafficRateExhausted`，卡片会原样提示该原因（不是密码问题），可减小包体积或等额度重置
- 云端保留份数请留意网盘容量：每份约 70–150 MB，免费版 1 GB 额度下 10 份即接近上限
- 加密功能依赖 `cryptography`（DriFox 自带）
