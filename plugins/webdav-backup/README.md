# webdav-backup

将 DriFox 数据全量备份到任意 WebDAV 网盘（坚果云、Nextcloud 等），支持定时自动备份、AES-256 加密、历史版本管理与一键恢复。

## 功能

- **范围可选**：设置卡按类勾选备份内容（会话/助手数据/插件配置/已装插件/技能/团队/工作流/项目/归档/工作区/截图/本地备份），另支持「额外包含」补充清单外目录；数据目录根部散文件（数据库/配置）始终包含
- **全量备份**：自动排除日志、缓存、锁文件与超过 200MB 的单文件
- **定时备份**：距上次成功备份超过设定间隔（默认 24 小时）自动执行，无需打开卡片
- **可选加密**：设置加密密码后备份包经 AES-256-GCM 加密（PBKDF2-SHA256 派生密钥，480k 轮），扩展名 `.dvp`；留空则为普通 zip，可用任意解压工具打开
- **版本管理**：远端保留最近 N 份（默认 10），超出自动清理最旧
- **一键恢复**：从备份列表选择恢复，覆盖前自动在系统临时目录留存回滚副本
- **AI 工具**：对话中可让 AI 调用 `webdav_backup`（测试连接/列出/备份）与 `webdav_restore`（恢复）

## 配置

设置 → 插件 → WebDAV 备份：

| 字段 | 说明 |
|------|------|
| 服务器地址 | 坚果云：`https://dav.jianguoyun.com/dav/`；Nextcloud：`https://你的域名/remote.php/dav/files/你的用户名/` |
| 账号 | 坚果云填注册邮箱 |
| 密码 | 坚果云必须用「应用密码」（网页端 账户信息 → 安全选项 → 添加应用密码），不能用登录密码 |
| 备份加密密码 | 留空不加密；设置后备份包加密上传，恢复时需同一密码 |

## 注意

- 备份在后台线程执行，DriFox 运行中备份时 SQLite 可能存在极小概率的写入窗口，追求绝对一致可在备份前关闭 DriFox
- 恢复会覆盖本地数据，覆盖前自动留回滚副本（路径在恢复结果中给出）；恢复完成后需重启 DriFox 生效
- 坚果云免费版有流量与请求频率限制，备份间隔不宜低于 1 小时
- 加密功能依赖 `cryptography`（DriFox 自带）
