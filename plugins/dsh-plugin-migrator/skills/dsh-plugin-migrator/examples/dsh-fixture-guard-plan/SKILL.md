# 施工平面图合规校核

按下列维度逐项校核，缺任一项都不能下结论。

## 校核维度

| 维度 | 判据 | 常见失效 |
|---|---|---|
| 防火间距 | 与相邻建筑的净距 | 图上标注距离含外墙装饰层 |
| 疏散通道 | 净宽与转弯半径 | 通道被临时堆场占用 |
| 危化品分区 | 与明火区的隔离 | 分区边界与通风方向冲突 |
| 持证要求 | 作业类型对应资质 | 特种作业证过期 |

## 反模式

- 只看图上标注尺寸，不看图例与比例尺
- 把「方案里写了」当作「已落实」
- 用其他辖区的规范套本地项目

## 输出

给出逐项结论（符合 / 不符合 / 无法判定），并写明无法判定所需的补充材料。
