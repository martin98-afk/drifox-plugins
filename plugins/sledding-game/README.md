# Sledding Game · 初雪坡

浅色动画主题：仓鼠与青蛙坐雪橇滑下雪坡的 4K 手绘动画整窗铺底，雪青基调，河蓝 accent。

## 内容

| 组成 | 素材来源 |
|------|---------|
| 动画背景 `themes/*/bg/chat.webp` | Wallpaper Engine 创意工坊 `3531878415`（Sledding Game）的 `Sledding.mp4`，3840×2160@11.25s，转制 800×450@12fps 动画 WebP（135 帧，0.77MB） |

## 主题能力演示

- `window.animation` — 动画 WebP 整窗铺底（`fit: cover`，opacity 0.95）
- `sidebar` — 半透明浅青罩（alpha 145）透出窗层动画
- `scene` — 极淡白罩（alpha 40）保对话区文字可读
- 配色：accent 河蓝 `#3e86ad`（取自雪坡滑痕）、accent_warm 主角橙 `#c8783a`，96 键 token 全集浅色派生
