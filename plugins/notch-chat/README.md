# 顶边快捷对话（notch-chat）

macOS 顶边胶囊，一键展开一条独立的纯文本对话。与主窗口当前会话互不影响，收起后继续在后台跑。

## 用法

| 操作 | 效果 |
|------|------|
| 左侧自定义插件栏「顶边快捷对话」 | 展开 ↔ 隐藏 |
| `⌃⌥K`（全局） | 展开 ↔ 收起，展开时直接聚焦输入框 |
| `Enter` | 发送 |
| `Shift+Enter` | 换行 |
| `Esc` | 收起，保留草稿和在途回复 |
| 输入框右侧按钮 | 空闲时发送，回复中变为「停止」 |
| 底部「新会话」 | 清空本窗对话重新开始（不影响主窗口） |
| 底部「在主窗打开」 | 落库并在主窗口打开，可继续在那里聊（会停掉主窗当前回复） |

快捷键在插件加载后注册，依次尝试 `⌃⌥K`、`⌃⌥J`、`⌃⌥空格`，取第一个可用的；全部被占用时胶囊照常可点，底部提示会显示占用的组合。

## 状态胶囊

收起后停在屏幕顶部居中（菜单栏下方），只显示本对话状态，不显示标题或正文：

| 标记 | 状态 |
|------|------|
| `○` | 待机 |
| `◐` | 等待回复 |
| `●` | 正在回复 |
| `✓` | 已完成 |
| `◌` / `■` | 正在停止 / 已停止 |
| `!` | 发送失败 |

## 行为口径

- 独立会话：不读也不写主窗口当前对话，多轮上下文只在本窗内累积。
- 多轮：每轮把提问与回答一起带给模型，无需重新交代背景。
- 工具：沿用宿主当前 agent 的工具清单，执行策略为自动允许（不弹审批），因此模型可直接读写文件、跑命令，注意上下文。
- 附件：暂不支持。
- 主题：跟随 DriFox 深浅主题自动切换。
- 常驻：切到其他应用、最小化主窗口都不影响小窗；只有应用退出或插件停用才销毁。
- 关闭：窗口随应用退出销毁；插件停用时取消在途请求并释放会话。

## 已知限制

- 仅 macOS。其他平台不注册任何入口。
- 收起态落在菜单栏下方，不占据物理刘海区域。
- 重启 DriFox 后窗内对话不保留；要长期保留请用「在主窗打开」落库。
- 全局快捷键固定三选一，暂不可在设置里改。
- 「在主窗打开」会先停掉主窗口正在进行的回复，再加载；落库后要等约 3 秒才切过去。

## 结构

```
notch-chat/
├── .drifox-plugin/plugin.json   # 能力：engine.session
├── ui/__init__.py               # 侧栏入口 + 单例与清理
├── ui/panel.py                  # 胶囊 / 卡片 / 输入区 / 主题
├── ui/chat.py                   # 轮次状态机、流式、取消、历史
├── ui/hotkey.py                 # macOS 全局热键（Carbon）
└── tests/                       # 控制器与面板回归 + 离屏连拍
```

对话能力走宿主公开契约 `engine.session`（`turn(callbacks=..., auto_history=...)`），不自建引擎，也不直接读模型密钥。
