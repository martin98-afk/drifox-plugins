# 最后生还者 · The Last of Us
深浅双模式主题：Ellie 林间弹吉他场景整窗铺底，附四首 OST 背景音乐。

## 内容
| 组成 | 素材来源 |
|------|---------|
| 场景背景 `themes/*/scene.png` | Wallpaper Engine 创意工坊 `1998201410`（Last of Us）的 `materials/EQgpkwGWsAIEtcQ.tex`，内嵌 PNG 提取，1920×1080 |
| 背景音乐 | `2860240798` 的三首 Gustavo Santaolalla OST（The Path (A New Beginning) / The Last of Us / Left Behind）+ `1998201410` 的 Theme Song |

## 主题能力演示
- `window` — 主背景图整窗铺底 + `dim` 蒙版压暗，`sidebar` 半透明罩，`scene` 纯透明让窗口层透出
- `music` — 四首 OST 循环播放，`fade_ms: 420`

## 深浅两套
| 主题 | mode | 调性 |
|---|---|---|
| 最后生还者 · 林间暮色 | dark | 深绿黑底 + 琥珀 accent，取色自画面枯木与透光 |
| 最后生还者 · 林间晨光 | light | 暗图淡化 + 模糊做出晨雾感，卡片米白 |

## 音乐行为
- 切到本主题自动播放，切走立即停止
- 应用失焦自动暂停，切回续播
- 音量由「设置 → 外观 → 主题音乐音量」控制
