# Designkit

Create and revise visual designs and presentations with Designkit, then download the finished files.

## 启用

设置 → MCP 连接器 → 找到本插件 → 启用。工具名前缀 `mcp__designkit__`。

## 认证

无需预置密钥，启用后直连。端点为 WorkBuddy 定制路径，若连接被拒可能需要服务方开通访问权限。

## 上游

- 服务方端点: `https://designkitmcp.designkit.com/mcp/workbuddy`
- 传输: streamable HTTP
- 来源: WorkBuddy 连接器市场（connector-plugins 整包）

## 示例

- 制作一份介绍智能台灯的三页英文演示文稿。
- 为虚构书店的周末活动设计一张方形海报。
- 修改刚才的演示文稿并导出可编辑 PPTX。

## 技能

随插件内置 AI 技能（AI 按任务自动匹配，无需手动调用）：

- `designkit`

注：技能正文沿用服务方原文（含其官方脚本），个别操作指引以 WorkBuddy/CodeBuddy 环境为例，DriFox 下以实际可用工具为准。
