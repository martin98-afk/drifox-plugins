# quick-screenshot

> DriFox 输入框工具栏一键选区截图：左键按钮 → 全屏拖框 → 松手自动复制到系统剪贴板 → 切回输入框 Ctrl+V 即变附件芯片；右键按钮 → 隐藏 DriFox 主窗后选区截图，可截身后的画面。

## 用途

主程序内置的 `screenshot` 工具是给 AI 用的全屏截图，缺一个**用户侧**的「圈一块 → 复制 → 贴进来发问」快速通道。本插件补上：

- 不用切换到 Snipaste / 微信截图
- 自动进剪贴板，粘贴到 DriFox 输入框直接变附件芯片
- 高 DPI 屏（125% / 150%）截图像素尺寸与屏幕实际区域一致
- 零配置

## 交互流

### 左键：快速截图

1. 点输入框工具栏的裁剪图标按钮（位于「新建会话」按钮左侧）
2. 全屏变暗可拖框：选区外半透明黑遮罩，选区内显示原画面，青色边框 + 右上角尺寸角标（如 `640×480`）
3. 松手 → 弹出 InfoBar 绿色提示「截图已复制到剪贴板 W×H」，系统剪贴板已有图
4. 切回 DriFox 输入框 Ctrl+V → 图片变附件芯片，发送即可

### 右键：隐藏窗口截图（截 DriFox 身后的画面）

1. 右键点同一按钮 → DriFox 主窗隐藏
2. 等待约 280ms 屏幕合成刷新后抓主屏底图，弹出同样的选区遮罩
3. 松手复制剪贴板 → **主窗自动恢复显示并抢回前台** → InfoBar 提示
4. Esc/右键取消 → 主窗同样恢复，不留残留状态

> 兼容旧主程序：`register_input_button` 无 `on_right_click` 参数时自动降级为纯左键模式（tooltip 同步变化）。

## 取消

- **Esc** / **右键** / **单击（选区过小）**：静默取消，无任何残留

## 已知限制

| 项 | 当前实现 | 后续迭代 |
|----|---------|---------|
| 显示器 | 仅主屏（多屏环境请确保目标在主屏） | 多屏支持 |
| 编辑 | 纯选区，无标注（不画笔/马赛克/文字） | 标注编辑 |
| 自动插入 | 不自动插入输入框（统一走剪贴板 + Ctrl+V） | 可选自动插入 |
| 隐藏主窗 | 右键按钮触发（隐藏 → 抓屏 → 恢复），左键仍含主窗 | 多屏/延迟可配置 |
| 全局快捷键 | 无（依赖按钮点击） | 可接 shortcut-manager |

## 架构（冻结底图方案）

点按钮瞬间 `QScreen.grabWindow(0)` 抓主屏全屏作底图；全屏无边框置顶遮罩窗铺底图（**所见即所截**）；拖框时选区外叠半透明暗遮罩；松手从底图按 `devicePixelRatio` 换算裁剪物理像素区域，复制到剪贴板。

## 结构

```
quick-screenshot/
├── .drifox-plugin/
│   └── plugin.json           # manifest（仅启用 ui 组件）
├── icon.svg / icon_dark.svg  # 插件管理列表图标
├── README.md                 # 本文件
└── ui/
    ├── __init__.py           # register_ui：注册按钮（左键截图/右键隐藏截图）+ 抓屏 + 剪贴板写入 + InfoBar 提示
    ├── overlay.py            # _ScreenshotOverlay：全屏遮罩窗（拖框、信号槽、高 DPI 换算）
    └── icons/
        ├── screenshot.svg        # 深色主题按钮图标
        └── screenshot_light.svg  # 浅色主题按钮图标
```

## 安装

1. 在 DriFox 插件市场搜索「quick-screenshot」一键安装
2. 或手动：将本目录复制到 `~/.drifox/plugins/quick-screenshot/`
3. 重启 DriFox → 输入框工具栏出现裁剪图标（位于新建会话按钮左侧）

## 配置

无（`plugin.json` 不声明 `config_schema`，主程序不渲染设置卡）。

## 依赖

仅依赖主程序内置能力（PyQt5 + qfluentwidgets + loguru），零第三方新依赖。
