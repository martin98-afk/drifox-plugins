# AWS Knowledge

检索 AWS 官方文档、最佳实践与区域可用性信息。

> 由 HanaAgent 官方市场连接器迁移而来。指向服务方自营的远程 MCP 服务器，
> 本插件不含服务端代码，也不托管任何凭据。

## 启用

设置 → MCP 连接器 → 找到本插件 → 启用。工具名前缀 `mcp__hana-aws-knowledge__`。



## 上游

- 服务方端点: `https://knowledge-mcp.global.api.aws`
- 来源: HanaAgent 官方市场（official-global）
- 上游仓库: https://github.com/liliMozi/hana-connectors
