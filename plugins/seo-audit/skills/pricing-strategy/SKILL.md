## 9 大定价模型

### 1. Flat Rate（统一定价）

```
$99 / 月，无论规模
```

✅ 简单透明
❌ 大客户嫌贵，小客户嫌多

**适用**：早期产品、简单工具

### 2. Per User（按用户）

```
$10 / 用户 / 月
```

✅ 随规模增长
❌ 团队共享时用户数不准

**适用**：协作工具（Slack、Notion）

### 3. Per Usage（按用量）

```
$0.01 / API 调用
$0.05 / GB 存储
```

✅ 用多少付多少
❌ 收入难预测

**适用**：API、基础设施（AWS、Stripe）

### 4. Tiered（分层定价）

```
Free → Pro $20 → Business $50 → Enterprise 自定义
```

✅ 覆盖全用户
❌ 阶梯多会混乱

**适用**：大多数 SaaS

### 5. Freemium（免费 + 增值）

```
免费版：基础功能
付费版：高级功能
```

✅ 拉新快
❌ 转化率低（1-5%）

**适用**：工具型产品（Dropbox、Notion）

### 6. Free Trial（免费试用）

```
14 天免费试用
30 天免费试用
```

✅ 体验完整产品
❌ 用户忘记取消

**适用**：复杂产品（B2B SaaS）

### 7. Reverse Trial（反向试用）

```
14 天 Pro → 自动降级 Free
```

✅ 体验付费后保留
❌ 法律风险（自动付费）

**适用**：自助产品

### 8. Usage-Based Hybrid（混合）

```
$50 基础 + $0.01 / 调用
```

✅ 稳定 + 弹性
✅ 客户接受度高

**适用**：API 平台（Twilio、Algolia）

### 9. Custom Enterprise（企业定制）

```
联系销售
```

✅ 大单
❌ 周期长

**适用**：B2B 大客户

## 3 层定价阶梯

```
┌─────────────────────────────────────┐
│  Enterprise 自定义                   │  ← 10% 客户贡献 50% 收入
│  ★ 联系销售 · SSO · SLA · 审计      │
├─────────────────────────────────────┤
│  Pro $XX / 月 / 用户                  │  ← 主力（60% 收入）
│  ★ 高级功能 · 无限用量 · 优先级支持  │
├─────────────────────────────────────┤
│  Free $0                              │  ← 漏斗顶部
│  ★ 基础功能 · 1-3 用户 · 社区支持    │
└─────────────────────────────────────┘
```

### Free → Pro 的升级触发

| 触发点 | 时机 |
|--------|------|
| 用量限制 | 已经超 80% |
| 用户数限制 | 已经 5/3 |
| 功能限制 | 已经用 advanced 关键词 |
| 时间限制 | 14 天 reverse trial |
| 集成限制 | 已经有 2 个集成 |

### Pro → Enterprise 的升级触发

| 触发点 | 时机 |
|--------|------|
| SSO / SAML | 企业 IT 要求 |
| 审计日志 | 合规要求 |
| SLA 99.9% | 业务关键 |
| 私有部署 | 数据安全 |
| 自定义合同 | 法务要求 |

## 价格锚定（Price Anchoring）

### 1. 锚定效应

```
显示 $99/月 高价（实际无人选）
然后显示 $19/月（看起来便宜）
```

**效果**：用户会倾向 $19。

### 2. 中央选项陷阱

```
用户大多数选中间档（80%）
→ 把"想卖"的放中间
```

### 3. 年付折扣诱饵

```
月付 $24
年付 $19（节省 20%）
→ 80% 选年付（现金流 + 留存）
```

### 4. 锚定公式

```
高价 = 月付 × 3 倍
中价 = 月付 × 1.5 倍
低价 = 月付 × 0.5 倍
```

## 价值阶梯（Value Ladder）

```
免费 → 低价 → 中价 → 高价 → 企业 → 定制
低价值 → 高价值
低承诺 → 高承诺
```

### 案例

| 产品 | 免费 | 低价 | 中价 | 高价 | 企业 |
|------|------|------|------|------|------|
| Notion | Free | $10/月 | $15/月 | - | 定制 |
| Figma | Free | $12/editor | $45/editor | $75/business | 定制 |
| Vercel | Hobby | $20/月 | $20/月/成员 | $250/月 | 定制 |

## 定价心理学

### 1. 9 字尾定价

```
$19 vs $20
$99 vs $100
$199 vs $200
```

→ 9 字尾**感知更便宜**（左数字决定认知）。

### 2. 数字进位

```
$19 → $20：用户感觉"涨价"
$19 → $21：用户感觉"小涨"
```

### 3. 锚定组合

```
$29 / 月 / 月付
$24 / 月 / 年付（节省 20%）
```

```
$290 / 用户 / 年付（买 1 送 1）
```

### 4. 套餐"最适合谁"

```
✅ Free：刚开始的个人 / 小团队
✅ Pro：成长中的团队（5-20 人）
✅ Business：规模化企业（20+ 人）
✅ Enterprise：需要定制的企业
```

描述"用户"而非"功能"。

## 计费策略

### 1. 月付与年付

```
年付折扣：15-25%
```

### 2. 多年付

```
2 年付：30% 折扣
3 年付：40% 折扣
```

适合企业客户。

### 3. 试用策略

| 策略 | 周期 | 转化率 |
|------|------|--------|
| Free Trial | 14 天 | 15-25% |
| Free Trial | 30 天 | 20-30% |
| Reverse Trial | 14 天 | 25-40% |
| Freemium | 永久 | 1-5% |

### 4. 升级与降级

```
升级：即时生效，按比例计费
降级：下个周期生效
切换：年付↔月付，年付计费
```

## 5 个反模式

### 1. 4 个套餐（过多）

```
❌ Free / Starter / Pro / Business / Enterprise
✅ Free / Pro / Enterprise
```

### 2. 价格数字奇怪

```
❌ $17.42 / 月
✅ $19 / 月
```

### 3. 没有"锚定"

```
❌ $19 / 月
✅ ~~$29~~ $19 / 月 （限时优惠）
```

### 4. 主力放最便宜

```
❌ Free 100% 推荐 / Pro 也推荐
✅ Pro 100% 推荐（最受欢迎）
```

### 5. 隐藏企业版

```
❌ 企业版隐藏在 footer
✅ Enterprise 套餐明确展示
```

## 定价页模板

```markdown
## 定价页面结构

1. **价值主张**（≤ 30 字）
   "5 分钟搭建内部工具，无需从头开发"

2. **3 个套餐卡片**
   - Free：适合个人
   - Pro（最受欢迎）：适合团队
   - Enterprise：适合企业

3. **每套餐要素**
   - 套餐名 + 简介
   - 价格 + /月 / /用户
   - 5-7 条核心特性
   - 1 个 CTA 按钮
   - "最适合谁" 描述

4. **对比表**（详细功能横向）

5. **FAQ**（5-8 问）
   - 能取消吗？
   - 支持哪些支付？
   - 发票/合同？
   - 学生/非营利折扣？
   - 退款政策？

6. **信任元素**
   - 客户 logo
   - 安全认证
   - 数据备份

7. **终极 CTA**
   "立即开始 · 30 天试用 · 无需信用卡"
```
