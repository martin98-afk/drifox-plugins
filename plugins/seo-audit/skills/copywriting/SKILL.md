# Copywriting 技能 — 高转化落地页文案

本技能为 AI 提供可套用的市场文案撰写方法论，让 AI 撰写**真正能转化**的页面文案，而不是 AI 味的假大空。

## 何时触发

- "帮我写主页文案"、"写落地页"
- "定价页怎么写"、"定价表怎么设计"
- "headline 怎么写"、"CTA 文案"
- "产品介绍写不出来"、"价值主张怎么提炼"

## 核心原则（Corey Haines 框架）

### 1. 清晰优于聪明

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| "在数字时代赋能您的业务" | "30 分钟搭建内部工具" |
| "重新定义团队协作" | "Slack 的开源替代品" |
| "无缝集成、卓越体验" | "一键导入 Notion / Google Docs" |

### 2. 具体优于抽象

| ❌ 抽象 | ✅ 具体 |
|--------|--------|
| "我们提供强大的解决方案" | "94% 用户一周内学会" |
| "高效的工作流" | "3 步完成季度报告" |
| "企业级安全" | "SOC 2 Type II + GDPR + 自托管" |

### 3. 短句优于长句

每句 ≤ 20 字。每段 ≤ 3 句。

### 4. 动词优于名词

用 `start` / `build` / `ship` / `save` / `automate`，避免 `solution` / `platform` / `ecosystem`。

### 5. 第二人称直接对话

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| "用户可以创建..." | "你可以创建..." |
| "该产品支持..." | "你可以..." |

## 页面文案结构

### 🏠 主页（Home）

```
1. Hero
   - Headline（≤ 8 字，传达核心价值）
   - Subheadline（≤ 30 字，解释怎么做到）
   - CTA 主按钮 + 次按钮

2. Social Proof
   - 客户 logo
   - 真实用户证言（含角色 + 数据）

3. 核心价值（3-4 benefit）
   - icon + 标题 + 50 字

4. How it works（3 步）
5. 详细 features（6-8 个）
6. 案例研究（1-2 个，含数据）
7. 定价简述（3 套餐）
8. FAQ（5-8 问）
9. 终极 CTA + 风险反转
```

### 🚀 落地页（Landing）

```
1. Hero（强 attention）
   - Hook（1 句抓眼球）
   - 大标题（≤ 12 字）
   - 副标题（痛点共鸣）
   - CTA

2. 痛点放大（3-5 条）
3. 解决方案
4. How it works（3 步）
5. 社会证明（强烈 + 数据）
6. 反对意见解答（3-5 条）
7. 终极 CTA + 风险反转
```

### 💰 定价页（Pricing）

```
1. 价值主张（≤ 30 字）
2. 3 套餐（Free / Pro / Enterprise）
   - 名称 + 价格
   - 5-7 核心特性
   - CTA
   - "适合谁" 描述
3. 对比表（详细功能）
4. FAQ（5-8 问）
5. 信任元素
6. 终极 CTA
```

## 受众适配

| 受众 | 关注点 | 文案关键词 |
|------|--------|-----------|
| developer | 性能、API、DX | 代码、benchmark、typed |
| founder | 增长、ROI | 案例、ROI、增长 |
| marketing | 转化、品牌 | 转化率、品牌故事 |
| enterprise | 安全、合规 | SSO、SOC2、SLA |

## 风格指南

| 风格 | 适用场景 | 关键词 |
|------|---------|--------|
| professional | B2B SaaS、咨询 | proven、trusted、standard |
| friendly | 消费级 | simple、enjoy、easy |
| bold | 颠覆性产品 | transform、break、first |
| playful | 创作者工具 | fun、play、build |
| technical | 开发者工具 | performant、typed、observable |

## 应避免

- ❌ `revolutionize` / `synergy` / `leverage` / `cutting-edge`
- ❌ `我们致力于...` / `我们努力成为...`
- ❌ 堆砌形容词（强大、灵活、可扩展的解决方案）
- ❌ 否定表述（"你不必担心..."）
- ❌ "完整解决方案" / "一站式平台"（无信息量）

## 输出模板

撰写完成后强制输出以下三部分：

1. **完整文案**（Markdown）
2. **关键决策**（为什么这样写）
3. **A/B 测试建议**（哪些元素可测试）
