# Banner Design：多格式创意横幅系统

跨社交、广告、网页与印刷格式设计横幅。给出多个美术方向，视觉元素用 CSS 构建、用户提供，或按需生成。本技能只管横幅设计，不做视频剪辑、整站设计、印前生产。

## 什么时候用

- 用户要求横幅、封面、页头设计
- 社交媒体封面的制作
- 广告 banner 或展示广告设计
- 网站 hero 区的视觉设计
- 活动横幅或印刷横幅
- 市场活动的创意素材

## 可用资源

本流程自包含：不依赖同级技能，也不需要技能相对路径的脚本。尺寸、安全区、美术方向用 `references/banner-sizes-and-styles.md`。浏览器调研、图片生成、截图工具都是可选能力；没有时就用用户提供的素材、CSS 构建的视觉，以及运行环境自带的预览或截屏流程。

## 工作流

### 第 1 步：收集需求

向用户问清：

1. **用途**：社交封面、广告横幅、网站 hero、印刷，还是创意素材？
2. **平台/尺寸**：哪个平台，或自定义尺寸？
3. **内容**：标题、副文、CTA、logo 位置？
4. **品牌**：已有品牌指南、logo 文件、配色或字体？
5. **风格偏好**：有美术方向吗？（拿不准就给几个选项）
6. **数量**：出几个方向？（默认 3 个）

### 第 2 步：调研与美术方向

1. 读 `references/banner-sizes-and-styles.md`，确认目标格式、安全区与适配风格。
2. 浏览器调研可用且被允许时，收集 3 到 5 个构图与美术方向的参考；否则基于随包参考与用户提供的示例工作。
3. 选 2 到 3 个互补的美术方向，说明每个方向如何服务横幅的用途。

### 第 3 步：设计并生成方案

对每个美术方向：

1. **用 HTML/CSS 做横幅**
   - 用尺寸参考里的精确平台尺寸
   - 遵守安全区：关键内容放中间 70% 到 80%
   - 最多 2 种字体、单一 CTA、文字对比度至少 4.5:1
   - 用用户提供的 logo、配色、字体与图像；不要发明品牌规则
2. **选视觉来源**
   - 优先用用户提供的、或授权明确的素材
   - 用渐变、几何形、排版等 CSS 构建的视觉，保证零依赖
   - 运行环境若有授权的图片生成能力，可以按目标比例生成背景或插画
   - 生成的提示词里不要出现文字与字母，保证最终文案在 HTML 里可编辑、可访问
3. **合成最终横幅**：在 HTML/CSS 里叠标题、副文、CTA 与 logo，然后按精确目标尺寸核对层级、安全区、对比度与裁切表现

### 第 4 步：导出图片

1. 在可用浏览器里按精确视口预览每个横幅。
2. 用运行环境自带的浏览器或截图能力把横幅元素截成 PNG。截图不可用就交付 HTML/CSS 源码，并明确标注 PNG 导出未完成，不要点一个没装过的工具的名字。
3. 核对导出像素尺寸、安全区裁切、字体加载与图像质量。
4. 导出文件超平台限制时，用可用的图片优化工具，或在平台规范内降质量、缩尺寸。

**输出路径约定**：

```
assets/banners/{campaign}/
├── minimalist-1500x500.png
├── gradient-1500x500.png
├── bold-type-1500x500.png
├── minimalist-1080x1080.png    # 多尺寸时
└── ...
```

- 文件名用 kebab-case：`{style}-{width}x{height}.{ext}`
- 时效性活动加日期前缀：`{YYMMDD}-{style}-{size}.png`
- 活动文件夹归拢所有变体

### 第 5 步：展示方案并迭代

并排展示所有导出图，每个方案给出：

- 美术方向名称
- 导出的 PNG 预览（截图不可用时给 HTML/CSS 预览）
- 关键设计理由
- 文件路径与尺寸

按用户反馈迭代，直到确认。

## 美术方向（前十）

| 风格 | 适合 | 关键元素 |
|------|------|---------|
| 极简 | SaaS、科技 | 留白、1 到 2 种颜色、干净的排版 |
| 大字排版 | 公告 | 超大字号作为主角 |
| 渐变 | 现代品牌 | 网格渐变、色相混合 |
| 照片 | 生活方式、电商 | 满幅照片加文字叠层 |
| 几何 | 科技、金融科技 | 形状、网格、抽象图形 |
| 复古 | 餐饮、手作 | 做旧质感、低饱和 |
| 玻璃拟态 | SaaS、应用 | 磨砂玻璃、模糊、发光描边 |
| 霓虹/赛博 | 游戏、活动 | 深色底、霓虹光 |
| 杂志编排 | 媒体、奢侈品 | 栅格版式、引文块 |
| 3D/雕塑感 | 产品、科技 | 渲染物体、景深、投影 |

全部 22 种风格见 `references/banner-sizes-and-styles.md`。

## 设计规则

- **安全区**：关键内容放在画布中间 70% 到 80%
- **CTA**：每条横幅一个，右下角，高度至少 44px，用动词
- **字体**：最多 2 种，正文至少 16px，标题至少 32px
- **文字占比**：广告低于 20%（Meta 会惩罚文字过多的素材）
- **印刷**：300 DPI、CMYK、3 到 5mm 出血
- **品牌**：只用用户提供且经过核对的品牌规范与素材
