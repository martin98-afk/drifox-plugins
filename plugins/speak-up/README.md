# speak-up · 主动搭话

没人跟 AI 说话的时候，它自己也有可能先开口。

移植自 [dsh-speak-up](https://github.com/Yuuyuko-uu/dsh-speak-up)（DeepSeek Harness 插件），
算法口径逐字对齐上游，宿主驱动层换成 DriFox 的能力池。

## 它做什么

定时器到点 → 本地掷一次骰子（**一个 token 都不花**）

- 没掷中 → 什么都不做，只在记账里记一笔
- 掷中 → 往当前会话送一句「内心话」，宿主照常开一轮对话

掷骰的判据是一条**命中线**：

```
命中线 = min(100, 档位命中线(峰/谷) × 时机因子 + min(加成上限, 连没中 × 没中加成))
```

掷出的点数（0~100）低于命中线才开口。顺序是**先乘时机因子、再加攒下来的加成**，最后夹到 0~100。

## 三个可调维度

| 维度 | 说明 |
|---|---|
| **峰谷分时** | 工作日 09:00-12:00、14:00-18:00 是峰时（贵），命中线压低少开口；其余时段含周末是谷时，命中线抬高多开口 |
| **时机因子** | 用户刚说完话（近阈值内）乘近因子把命中线压低；很久没说话（远阈值外）乘远因子抬高 |
| **攒加成** | 每没掷中一次，下次命中线加「没中加成」；加到「加成上限」就停。掷中清零，回到一开始 |

外加**安静时段**（可跨午夜）和**搭话冷却**（自己刚开过口后的一段时间内不重复）。

## 默认是演练模式

**试运行默认开着**：掷中了也只记账、不真发。先去「设置 → 主动搭话」看几轮记账，
确认口径符合预期再关掉试运行。记账里会写明每次的命中线怎么算出来的，例如：

```
掷中 ✓ 掷出 18.4（命中线 40.0 —— 掷到 40.0 以下就开口）
｜40.0 = 峰时命中线 20% × 时机因子 1.0（距上次说话 74.6 分钟） + 没中加成 20.0
｜没中加成清零（之前连着 2 次没中）
```

## 配置

全部在「设置 → 主动搭话」这个独立 tab 里（不占「设置 → 插件」的卡片流）。
底部的「演练一次 / 真发一次 / 恢复默认」用于当场验证。

## 能力边界

- 「距用户上次说话」读的是**当前会话**的消息列表。多会话场景下拿不到其它会话的时间，
  此时按「时间不明」处理（时机因子按 1 算），不是 bug。
- 冷却起点是「它真的说出话」那一刻，不是「投递成功」那一刻。
  投递只是把一句念头塞进会话，模型可以看完选择不说。
- 会话正在流式输出时不搭话（避免插进半截回答里）。

## 平台

Windows / macOS / Linux（纯 Python 标准库 + 宿主能力池，无外部依赖）。
