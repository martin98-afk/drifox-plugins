# bili-summary — B 站视频总结

> 目标：给定一条 B 站视频链接，用**可获取的公开数据 + 必要的画面识别**，产出一份能回答"这个视频到底讲了什么"的中文总结。
> 本文件是路由面。执行细节按需加载 `references/`，不要凭记忆猜接口。

## 1. 第一动作（必做，不可跳过）

1. **归一化输入**：从用户输入里提取视频标识。支持 `BV号` / `av号` / `b23.tv` 短链 / `bilibili.com/video/...` 完整链接。
   - 短链必须先跟随重定向取到真实 URL 再解析。
   - 多 P 视频：默认取第 1 P；用户指定 P 时用 `references/api.md` 的 pages 字段定位 cid。
2. **环境自检**：跑 `python scripts/check_env.py`。
   - 报告 ffmpeg 是否可用、能否连通 B 站、是否检测到 SESSDATA。
   - **ffmpeg 不可用 → 照 `references/fallback.md` 降级，不要尝试抽帧后静默失败。**
3. **按 §2 的阶梯逐层采数据**，每层都把结果落到临时目录，最后按 §3 出报告。

## 2. 采集阶梯（按序尝试，拿到就记录，拿不到就降级）

| 级别 | 数据源 | 免登录可用性 | 加载 |
|------|--------|------------|------|
| L0 | 视频元信息（标题/UP/简介/时长/分P/播放点赞数） | ✅ 可用 | `references/api.md` §L0 |
| L1 | 弹幕 XML | ✅ 可用（deflate 解压） | `references/api.md` §L1 |
| L2 | 评论 | ✅ 可用（**必须用 `/main` 端点**） | `references/api.md` §L2 |
| L3 | 官方 AI 总结 | ❌ 免登录返回 -403 | `references/api.md` §L3 |
| L4 | 字幕 | ❌ 免登录恒空，需 SESSDATA | `references/api.md` §L4 |
| L5 | 抽帧画面识别 | ✅ 可用（依赖本机 ffmpeg） | `references/frames.md` |

**阶梯纪律**：

- **L4 字幕默认跳过**。实测：无 Cookie 时字幕列表恒为空、`need_login_subtitle=true`，扫 10 个热门视频带字幕者 0 个。只有用户提供了 SESSDATA 才尝试，否则每次都白跑一级。
- **L2 必须用 `/main` 端点**。`x/v2/reply` 免登录只返回 3 条（不报错，静默裁剪），会让总结质量无声劣化。
- **L3 失败是常态**（-403），不要重试、不要当成错误中断流程。
- **L5 是真正的可靠底座**，不是兜底。当前三级（弹幕+评论+AI总结）都拿不到有效内容时，必须走抽帧。

## 3. 输出契约

产出**中文**总结，结构固定：

1. **一句话结论**：这个视频讲了什么（≤50 字）。
2. **内容概要**：分点叙述主线，每点标注**证据来源**（如 `[弹幕]` `[评论#3]` `[画面@02:10]`）。
3. **关键时间点**：画面/叙事发生转折的时间戳 + 一句说明（有抽帧数据时必给）。
4. **观众反馈**：高赞评论与高频弹幕反映的 reception（有数据时给）。
5. **数据来源与置信度**：列出实际拿到了哪几层（L0~L5），以及**没拿到哪层、为什么**。

置信度口径（必须如实标注，不许虚高）：

| 拿到了 | 置信度 |
|--------|--------|
| L0 + L4（有字幕） | 高 |
| L0 + L3（官方总结） | 高 |
| L0 + L1 + L2 | 中 |
| L0 + L5 抽帧 | 中 |
| 仅 L0 | 低 — 只能复述标题与简介，**必须明确说明无法覆盖视频本体** |

## 4. 渐进加载

| 阶段 | 读取 |
|------|------|
| 采集任一数据源 | `references/api.md` |
| 需要抽帧 | `references/frames.md` |
| 任一数据源失败 | `references/fallback.md` |
| 组织最终输出 | `assets/summary-template.md` |
| 接口疑似变动，要核对契约依据 | `references/domain-research-brief.md`（13 条实测证据卡） |

## 5. 硬停止

1. **ffmpeg 不可用** → 停。告知用户无法抽帧，按 `references/fallback.md` 降级交付，**禁止用标题/简介脑补画面内容**。
2. **视频不存在/已失效/需要登录** → 停。如实报告，不要猜测内容。
3. **只拿到 L0** → 置信度必须标低，并在报告里写明"未获取视频本体内容"。禁止把简介扩写成总结充数。
4. **接口返回 code ≠ 0** → 照 `references/fallback.md` 处理，禁止把错误响应当成内容解析。
5. **不允许编造时间戳、评论内容或画面描述**。每个断言都要能回指到某层真实数据。
