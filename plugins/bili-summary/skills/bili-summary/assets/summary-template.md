# 总结输出模板

> 结构固定，便于用户扫读与横向比较。删掉不适用的小节，但**不要删「数据来源与置信度」**。

```markdown
## 一句话结论

（≤50 字，这个视频讲了什么）

## 视频信息

| 项 | 值 |
|----|----|
| 标题 | |
| UP 主 | |
| 时长 | |
| 播放 / 点赞 | |
| 分 P | |

## 内容概要

1. **（小标题）** — （叙述）`[证据来源]`
2. **（小标题）** — （叙述）`[证据来源]`
3. ...

## 关键时间点

| 时间 | 发生了什么 | 来源 |
|------|-----------|------|
| 01:30 | | `[画面@01:30]` |
| 12:05 | | `[弹幕]` |

## 观众反馈

- 高赞评论：（引用 1-3 条，带点赞数）
- 高频弹幕：（概括弹幕中反复出现的反应/梗）

## 数据来源与置信度

- 置信度：**高 / 中 / 低**
- L0 元信息 ✅ / ❌
- L1 弹幕 ✅（N 条）/ ❌（原因）
- L2 评论 ✅（N 条）/ ❌（原因）
- L3 官方 AI 总结 ✅ / ❌ 不可用（免登录 -403）
- L4 字幕 ✅ / ❌ 需登录
- L5 抽帧 ✅（N 帧）/ ❌（原因）
```

### 证据来源标注规范

| 标记 | 含义 |
|------|------|
| `[弹幕]` | 来自弹幕内容 |
| `[评论#N]` | 来自第 N 条高赞评论 |
| `[画面@MM:SS]` | 来自该时间点的抽帧识别 |
| `[官方总结]` | 来自 B 站官方 AI 总结 |
| `[字幕]` | 来自字幕 |

每条概要**必须至少带一个来源标记**。没有来源的断言不许写进概要。
