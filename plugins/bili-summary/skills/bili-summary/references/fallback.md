# 降级契约

> 每一层都可能失败。失败时照这张表走，**不许重试刷屏、不许把失败当成功、不许脑补内容**。

## 逐层降级表

| 层 | 失败信号 | 动作 | 报告里怎么写 |
|----|---------|------|-------------|
| L0 元信息 | `code != 0` | **停止整个流程**，视频不存在/失效/需登录 | 如实报告，不产出总结 |
| L1 弹幕 | `code != 0` 或 XML 解析失败 | 跳过，继续 L2 | 「弹幕：未获取（原因）」 |
| L2 评论 | `code != 0` | 退回 `x/v2/reply`（3 条聊胜于无），再失败则跳过 | 「评论：未获取 / 仅 N 条」 |
| L2 评论（静默裁剪） | 用错端点只得 3 条 | 换 `/main` 重试一次 | 正常标注条数 |
| L3 AI 总结 | `code = -403` | **静默跳过**，不重试不报错 | 不出现在来源列表，或标「不可用（需登录）」 |
| L4 字幕 | `subtitles == []` 且 `need_login_subtitle=true` | 静默跳过 | 「字幕：需登录，未获取」 |
| L5 抽帧 | ffmpeg 缺失 / 非 0 退出 | 停抽帧，按已有数据交付并降置信度 | 「画面：未获取（ffmpeg 不可用）」 |

## 置信度强制规则

- 只有 L0（标题+简介）→ **低**。报告必须写明「未获取视频本体内容，仅基于标题与简介」。
- L1/L2 任一 + L0 → **中**。
- L4 或 L3 拿到 → **高**。
- L5 抽帧 + L0 → **中**（画面能提供叙事线，但没有台词精度）。

⚠ 抽帧失败**不能**靠"再看一遍标题"补回来。少一层就是少一层，如实写。

## 反模式（禁止）

- ❌ 把 `desc`（简介）扩写成"内容概要"冒充总结。
- ❌ 编造时间戳、评论、弹幕内容。
- ❌ 接口 -403 时反复重试不同端点刷屏。
- ❌ 用"根据标题推测视频可能……"输出正文。
- ❌ ffmpeg 缺失时跳过抽帧却不告知用户，让报告看起来是完整的。

## 合法降级示例

```markdown
## 数据来源与置信度

- 置信度：**中**
- L0 元信息 ✅
- L1 弹幕 ✅（1,203 条）
- L2 评论 ✅（50 条，热度序）
- L3 官方 AI 总结 ❌ 不可用（免登录 -403）
- L4 字幕 ❌ 需登录，未获取
- L5 抽帧 ❌ 本机未检测到 ffmpeg，跳过
```
