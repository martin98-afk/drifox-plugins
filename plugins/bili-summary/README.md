# bili-summary — B 站视频总结

通过弹幕、评论、官方 AI 总结与抽帧识别，概括一个 B 站视频到底讲了什么。

## 怎么用

安装插件后，直接把视频链接发给 AI 即可：

```
总结一下这个视频 https://www.bilibili.com/video/BV1GJ411x7h7
```

也支持这些形式：

- `BV1GJ411x7h7`（BV 号）
- `av80433022`（av 号）
- `https://b23.tv/xxxxxxx`（短链，会自动跟随重定向）

## 数据来源与阶梯

插件按下面的顺序采集数据，拿到哪层算哪层，并在报告里如实标注：

| 级别 | 数据源 | 免登录 |
|------|--------|--------|
| L0 | 视频元信息（标题/UP/时长/分P/播放量） | ✅ |
| L1 | 弹幕 | ✅ |
| L2 | 评论 | ✅ |
| L3 | 官方 AI 总结 | ❌（免登录 -403） |
| L4 | 字幕 | ❌（需 SESSDATA） |
| L5 | 抽帧画面识别 | ✅（需本机 ffmpeg） |

### 关于字幕

B 站对未登录用户不返回字幕。实测：即使 WBI 签名正确，无 Cookie 时字幕列表恒为空，
扫描 10 个热门视频带字幕者为 0。

因此**字幕层默认跳过**，不会每次白跑。需要字幕时提供 SESSDATA：

```bash
export BILI_SESSDATA=你的SESSDATA
```

### 关于抽帧

抽帧依赖本机 `ffmpeg`。缺失时该层自动跳过并在报告中标注，不会用标题脑补画面。

## 输出

- **一句话结论**
- **内容概要**（每条带证据来源标记，如 `[弹幕]` `[评论#3]` `[画面@02:10]`）
- **关键时间点**
- **观众反馈**
- **数据来源与置信度**（高/中/低，如实标注拿到了哪几层）

## 环境自检

```bash
python plugins/bili-summary/skills/bili-summary/scripts/check_env.py
```

## 说明

- 所有接口均为 B 站 Web 端公开接口，纯标准库实现，无第三方依赖。
- 接口契约记录于 `skills/bili-summary/references/api.md`，均经 2026-10-27 实测。
- B 站接口可能变动；若某层失效，报告会标注「未获取」，请对照 `references/fallback.md` 处理。
