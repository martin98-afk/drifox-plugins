# showcase — 成果展示

把模型要交付的文件、图片推到用户消息卡片的**成果栏**。

即梦插件里的成品会自己出现在成果栏，靠的是 `ToolResult.artifacts` 字段。这个插件把同一条通道开放给任意文件：模型判断「这个东西值得给用户看」，调一次 `showcase` 就行，不必写成特定格式，也不依赖任何生成类插件。

## 用法

模型侧（工具由 AI 自行调用）：

```python
showcase(paths=["out/poster.png"], caption="最终版海报")
showcase(paths=["out/demo.mp4", "out/frames"], caption="演示视频与截图")
showcase(paths=["dist"])          # 传目录，递归收集可预览文件
```

用户侧看到的成果栏：

| kind | 交互 |
|---|---|
| image | 折叠态出缩略图带；单击内置预览，左键拖拽导出，右键菜单 |
| video | 双击系统播放器；拖拽导出 |
| html | 双击浏览器打开；拖拽导出 |
| text | 双击系统关联程序；拖拽导出 |
| file | 同上（二进制文件按扩展名兜底） |

条目按 `path` 合并：同一轮里多次调用只追加增量，不会覆盖已有条目。

## 参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `paths` | ✓ | 文件路径列表，可混目录。相对路径以当前工作目录为基准 |
| `caption` | | 一句话说明。只展示单个文件时显示在该条目上 |

上限单次 50 项，超出部分不展示并在返回里提示剩余数量。目录只收图片/视频/网页/文本这些可预览的扩展名，避免误推整个代码仓库。

## 不需要 UI 组件

成果栏由宿主渲染，插件只需回传 `ToolResult.artifacts`。所以这个插件没有 `ui/` 目录，`components` 里只有 `tools`。

## 依赖

- 宿主 `>= 0.6.10`（`ToolResult.artifacts` 字段可用的版本基线）
- 更老的宿主不会崩：构造 `ToolResult` 时降级、丢掉 `artifacts`，功能退化为「在正文里告诉用户文件在哪」
