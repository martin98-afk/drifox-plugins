# twin-chat — ⚡ 并发对话

一个软件窗口，两路并发对话。

浮动卡片内嵌第二对话窗口实例（复用主程序 `OpenAIChatToolWindow` 复制模式）：
- **真并行生成**：独立 backend + 会话管理，主对话流式回复时，第二对话可同时发消息同时生成，互不排队
- **上下文继承**：创建时复制当前活跃窗口的项目上下文与模型选择，新空白会话起步
- **单实例**：插件始终只维护这一个对话实例；`/twin-chat` 切换显示/隐藏，隐藏时保留全部会话状态

## 使用

| 命令 | 说明 |
|------|------|
| `/twin-chat` | 打开/隐藏并发对话卡片（右侧浮动面板） |

## 原理

```
主对话窗口 (tab)  ──► backend A ──► 会话 A ─┐
                                             ├── 并行流式生成，互不阻塞
twin-chat 卡片   ──► backend B ──► 会话 B ─┘
     └─ OpenAIChatToolWindow(homepage, source_window=当前窗口)
        （复刻 _duplicate_window branch=False 链路，嵌入卡片容器）
```

复用主程序全部对话能力（消息渲染 / 工具调用 / 模型切换），主程序零改动。

## 依赖

- DriFox >= 0.4.15
- 组件：UI（浮动卡片）
