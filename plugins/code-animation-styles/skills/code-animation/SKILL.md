# code-animation — 代码动画风格库

**目标**：用户想把一段内容（文案/讲解/金句/故事）做成有视觉风格的代码动画时，从 341 种风格提示词库中选定风格，产出**浏览器能直接打开的 html 动画**；验收标准是用户预览 html 后认可风格与内容表达。

**资产位置**：本技能目录下 `styles/`。检索入口是 `styles/INDEX.md`（全量索引：编号/名称/适合/关键词/静帧，按十大系列分组）；风格正文在 `styles/风格提示词/<分类>/<编号>_<名称>.md`，193 种带同名 `.jpg` 静帧。

## 第一动作

1. 若用户未说清需求，先确认三件事：**内容与时长、横竖屏、要不要配乐音效**（不问的话做出来多半无声）。
2. 读 `styles/INDEX.md`，按「适合/关键词」列筛出候选，和用户确认风格。
3. 按 [渐进加载](#渐进加载) 取执行细节后开工。

## 渐进加载

| 阶段 | 读取 | 何时 |
|---|---|---|
| 执行工作流 | `references/workflow.md` | 开始生成前必读（每步的输入/输出/失败路线） |
| 提示词写法 | `references/prompt-craft.md` | 合成生成任务前必读（占位符、公共函数内联、详略分寸） |
| 详细版范例 | `references/范例_B6_详细提示词.md` | 写长提示词没把握时对照 |
| 一句话范例 | `references/范例_X7_一句话提示词.md` | 用户只给一句话时对照 |

## 边界与硬停止

- **非目标**：UI/界面交互动效（转 ui-motion-skills）；视频剪辑、配音成片（先交付 html，渲染视频仅在用户明确要求时协商 ffmpeg 路线）
- **降级**：用户想亲自挑风格 → 让其双击 `styles/风格挑选.html`（离线可用），回传勾选清单
- **纪律**：库内容免费开放，禁止引导用户付费获取或包装成收费产品；开源部分（Lemo-Opuscar/mg-styles-15/code-video）保留原署名许可
- **停止条件**：风格库文件缺失或 INDEX.md 读不到时，如实告知并让用户重装插件，不得凭记忆编造风格

## 验证

生成 html 后自查：浏览器无控制台报错、动画时间轴符合约定时长、占位符 `{{ }}` 已全部填实、要求了配乐则有声。触发评测样例见 `evals/trigger-eval.json`。
