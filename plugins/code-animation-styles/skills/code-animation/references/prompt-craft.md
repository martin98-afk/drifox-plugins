# 提示词写法分寸

## 详略两派

- **写死派**（颜色、时间、镜头全写死）：不同模型出片最接近，复现性最高。范例：`范例_B6_详细提示词.md`。适合：有明确脚本、要多风格衔接、要交付成片。
- **一句话派**：只给「漫画风的英雄短片」这种级别，模型自行发挥。每次结果都不同、更慢，但可能出彩。范例：`范例_X7_一句话提示词.md`。适合：探索风格、无硬性交付要求。

默认用写死派；用户明确说「你自由发挥」才用一句话派。

## 必做三件事

1. **填实占位符**：风格提示词里的 `{{ }}`（如 `{{标题文本}}`）必须替换为用户内容，交付前全文搜一遍 `{{` 确认清零。
2. **内联公共函数**：A–G 系列参考实现依赖同目录 `_公共函数.js`（rng/clamp/vgrad/glowDot/spawn 等）。生成 html 时把用到的函数一并内联，否则运行时报未定义。
3. **配乐音效写进任务**：需要声音就在生成时写明方案（Web Audio 合成音效 / 引用音频文件），并写触发时机（节拍、入场、转场）。事后补声等于重做。

## 时间与镜头约定

- 时间轴统一用秒，写清总时长与分镜边界（如 `0–3s 标题入场，3–8s 正文`）
- 镜头动作写死参数（位移/缩放的起止值与缓动），不写「动态一点」这类不可执行形容词
- 多风格衔接：写明每段的风格编号、进出转场方式（硬切/叠化/元素延续），元素延续优先（上一段末帧元素作为下一段开场）

## 模型差异预期

Opus 与 DeepSeek 都能用本库。提示词越细，两边出片越接近；一句话派两边差异明显。用户指定了模型就按其生成，不主动劝换。
