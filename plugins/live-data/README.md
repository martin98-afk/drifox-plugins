# live-data — 实时数据查询

大模型的训练数据有截止时间，「此刻的真实数值」——今天汇率多少、这个包最新版是几、
现在几度、这只股票现价多少——它只能靠猜。本插件把 8 个免密钥公开接口接进来，
聚合成 4 个工具，**不需要任何 API key，装上即用**。

迁移自 dsh 生态插件 `dsh-live-data`（原作者 istone，MIT），针对 DriFox 工具注册契约重写。

## 用法示例

```
今天美元兑人民币汇率多少

```

## 可选配置

只有一处，且只在 GitHub 限流时才需要：

```bash
export GITHUB_TOKEN=ghp_xxxx    # 或 GH_TOKEN
```

GitHub 未认证调用限额 **60 次/小时，按出口 IP 共享**——共用网络或 CI 环境下很容易打满。
不配也能用：主接口被限流时会自动回退到独立的搜索接口配额桶，两个都满才报错。

## 实测记录

以下结论均为 2026-10-27 本机实测，非文档转述：

- **pypi 走官方源，不走清华镜像**。实测 `pypi.tuna.tsinghua.edu.cn` 的 JSON 接口返回 **403 Forbidden**，
  而 `pypi.org/pypi/{pkg}/json` 正常。原插件用清华镜像，此处已改。
- **新浪财经返回 GBK**，必须按 GBK 解码。直接 UTF-8 解码会得到乱码。
- **新浪响应是多行 `var hq_str_xxx="..."` 文本，不是 JSON**。按 `hq_str_<代码>="` 定位再找配对引号取值。
- **上金所 `SGE_Au99.99` 恒返回空**。因此国内金价一块已去除，只保留国际伦敦金，
  并按 `元/克 = 美元/盎司 × 汇率 ÷ 31.1035` 折算，输出里注明这是原料价、不含零售溢价。
- **GitHub 403 限流要靠 `/rate_limit` 端点确认**，换了 3 种 User-Agent 都是 403，
  而 `/rate_limit` 始终 200 —— 说明是配额耗尽而非 UA 被拒。

## 输出约定

- 金额按中文习惯加「万/亿」单位，不用科学计数法。
- 风速附蒲福风级。
- 涨跌同时给绝对值和百分比。
- 每个结果末尾标注数据源，便于核对。

## 说明

- 纯标准库实现（仅 `urllib`），无第三方依赖。
- 所有请求带 15 秒超时，不会长时间挂起；失败时返回可读错误，不抛异常中断会话。
- 行情、汇率、金价数据**仅供个人参考，不构成投资建议**，实际成交以官方牌价为准。
