# 富途牛牛

富途牛牛是股票交易与行情数据连接器。支持港股、美股、A股、新加坡、日本、加拿大等多市场行情查询与交易下单，提供K线、资金流向、期权链、财报、研报、机构持仓、经济日历等全方位金融数据服务。

## 启用

设置 → MCP 连接器 → 找到本插件 → 启用。工具名前缀 `mcp__futu-mcp__`。

## 认证

无需预置密钥，启用后直连。行情与交易类工具需要富途牛牛账号授权，首次使用按工具返回的指引完成登录。交易下单涉及真实资金，请谨慎确认。

## 上游

- 服务方端点: `https://mcp.futunn.com/mcp`
- 传输: streamable HTTP
- 来源: WorkBuddy 连接器市场（connector-plugins 整包）

## 示例

- 查一下腾讯(00700)最新的股价和成交量
- 帮我下单买入100股苹果(AAPL)
- 查看我的港股持仓盈亏情况
- 分析一下比亚迪最近的资金流入流出情况

## 技能

随插件内置 AI 技能（AI 按任务自动匹配，无需手动调用）：

- `futu-mcp-skill`

注：技能正文沿用服务方原文（含其官方脚本），个别操作指引以 WorkBuddy/CodeBuddy 环境为例，DriFox 下以实际可用工具为准。
