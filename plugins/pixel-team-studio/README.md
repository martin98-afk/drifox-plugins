# 像素智能体团队工作室（pixel-team-studio）

> 实时可视化智能体团队与成员状态，拖拽像素小人组建团队。

## 功能

- **团队可视化**：所有团队（按运行 run 分组）以像素小人网格展示，实时查看每个成员的工作状态与上下文负荷
- **快捷建团**：点击「＋ 新建团队」从团队模板一键创建（复用 `/team --load` 链路，自动新建成员窗口）
- **拖拽组队**：从底部智能体库拖拽像素小人到团队面板即添加成员（新建成员窗口）；拖出成员到垃圾桶即移除（离开团队，窗口保留）
- **状态可视化**：每个像素小人显示
  - 工作状态徽标与状态点：空闲 / 忙碌 / 思考中 / 输出中 / 提问中 / 异常
  - 上下文负荷像素进度条（绿→黄→红，与主程序上下文圆环同源）
  - 悬停查看窗口 ID、未完成任务数
- **实时刷新**：5 秒轮询（上下文快照内部有 30s 工具 schema 缓存，开销可控）

## 使用

| 操作 | 方式 |
|------|------|
| 打开工作室 | 输入 `/pixel-team-studio` |
| 查看团队 | 团队竖排卡片列表（⭐ = 当前激活团队） |
| 新建团队 | 点击「＋ 新建团队」→ 选择模板 |
| 添加成员 | 双击智能体库小人 → 加入激活团队；或拖拽到指定团队面板 |
| 切到成员窗口 | 双击成员小人，或右键菜单「切到该成员窗口」 |
| 给成员发消息 | 右键成员小人 → 「✉ 给这个成员发消息…」，直接送达成员会话（不切窗口，复用团队邮件链路） |
| 移除成员 | 右键菜单「移除成员」，拖出团队面板释放，或拖到垃圾桶（窗口保留） |
| 手动刷新 | 头部 ↻ 按钮（平时 5s 自动轮询） |

> 拖拽时像素小人缩影会跟随鼠标；添加成员/新建团队后自动回到工作室窗口，不会被切走关闭。

## 交互约定

- **移除成员 = 离开团队**：窗口保留并恢复独立模式（与 `/team --leave` 一致），不会关闭窗口
- **添加成员 = 新建成员窗口**：每次拖入/点击都会创建新的成员会话窗口并加入当前团队（支持同角色多成员）
- **创建团队 = 新团队运行**：创建后新团队成为当前激活团队，历史团队仍保留在标签栏可切换查看

## 架构

```
ui/
├── __init__.py    register_ui 入口（浮动卡片注册）
├── cards.py       主卡片：头部统计/竖排团队列表/轮询刷新/拖放装配
├── widgets.py     FlowLayout / 成员格 / 智能体库 / 团队面板 / 垃圾桶（Qt 拖拽+双击+右键）
├── sprites.py     像素小人 QPainter 绘制（8-bit，角色专属配色与特征）
├── palette.py     主题色映射（文字亮度决定底色，黑底黑字免疫）
└── team_data.py   数据层：TeamManager / 窗口实例 / 模板 / 上下文快照
```

数据访问全部走 `team_data.py`（延迟 import `app.*`）：
- 团队/成员：`TeamManager.get_instance()`（`get_teams` / `get_members` / `get_team_run_ids`）
- 状态：窗口实时 `_ai_state`（streaming/thinking/question/error）→ 回退 `get_member_busy_status`
- 上下文：`backend.get_context_usage_snapshot()`（与上下文圆环同源）
- 操作：主窗口 `_spawn_team_members`（添加/建团）、`_handle_team_leave`（移除）
