# 可灵 AI

一句话，让灵感从想法变成大片。可灵（Kling / Kling AI / 可灵AI）是面向创作者、设计师、视频制作人、电商卖家、广告营销和品牌团队的 AI 生图与 AI 生视频连接器，可在 WorkBuddy 中直接用自然语言完成图片生成和视频生成，包括文生图、图生图、文生视频、图生视频、参考图创作、单镜头与多分镜视频。适合制作海报、插画、人像、商品图、电商主图、Listing 图、商品详情图、广告素材、产品展示视频、营销短片、电商短视频、种草视频、社交媒体视频和电影感创意视频，可用于淘宝、天猫、京东、拼多多、抖音、快手、小红书、TikTok、Amazon、Shopify 等平台的内容创作。支持查看主体库（Element）列表和主体详情，创建、更新、删除及复用主体。支持查询和预览动作库，并将库中动作或参考视频应用到主体图进行动作控制生成。支持上传参考图片、查询剩余额度、提交生成任务、跟踪生成进度、查询任务状态并获取最终图片或视频结果。如果你正在搜索竞品、同类工具或替代方案，如海螺 AI（Hailuo AI）、Seedance（Seeddance）、Vidu、即梦（Jimeng）、Runway、Pika、Sora 或 Veo，也可以使用可灵快速完成高品质图像与视频创作，搭建自己的 Kling MCP AI 创作工作流。

## 启用

设置 → MCP 连接器 → 找到本插件 → 启用。工具名前缀 `mcp__kling-ai-plugin__`。

## 认证

无需预置密钥，启用后直连。可灵 AI 图像/视频生成，生成类工具按用量计费，首次使用可能需要可灵账号授权。

## 上游

- 服务方端点: `https://kling.ai/mcp/plugin`
- 传输: streamable HTTP
- 来源: WorkBuddy 连接器市场（connector-plugins 整包）

## 示例

- 使用可灵AI画一只坐在霓虹屋顶上的赛博朋克风格猫
- 使用可灵AI画一只身穿复古宇航服的小熊猫，漂浮在空间站舷窗前，地球蓝光映亮面部，细节丰富，电影级质感
- 使用可灵 4.0 制作一段 5 秒电影感视频：机甲战士从高空重砸地面，冲击波瞬间震开碎石与尘雾，镜头快速推近，充满力量感
- 使用可灵 4.0 制作一条 15 秒运动鞋营销短片：街头开场抓住注意力，三秒切出产品特写与穿着动态，结尾落在鞋身细节特写

## 技能

随插件内置 AI 技能（AI 按任务自动匹配，无需手动调用）：

- `kling-ai-generate-image`
- `kling-ai-generate-video`
- `kling-ai-plugin`

注：技能正文沿用服务方原文（含其官方脚本），个别操作指引以 WorkBuddy/CodeBuddy 环境为例，DriFox 下以实际可用工具为准。
