# Humanizer 去 AI 味

把读起来像聊天机器人的文字，改成读起来像写它的人，内容一个字都不改。

迁移自 [blader/humanizer](https://github.com/blader/humanizer)（73k★，MIT，v4.0.0），技能正文译写为中文，`SKILL.en.md` 保留上游英文原文。

## 它治什么

模型写的是「下一个最可能的词」，所以默认收敛到最安全、最中庸的表达。这份技能把那些默认逐条列出来，一共 6 类 26 种：

| 类别 | 典型痕迹 |
|---|---|
| A 铺陈而非陈述 | 不是 X 而是 Y、一句话收尾、听起来很深的格言、先铺垫再给结论、和不存在的人辩论 |
| B 按规则造节奏 | 硬凑三连、连续同头句、破折号当万能连接符、限定语叠加、被动语态 |
| C 膨胀与借来的权威 | AI 高频词、夸大意义、含糊关联、空泛 -ing 短语、推销腔、专家认为、回避「是」「有」 |
| D 按规则排版 | 加粗当装饰、装饰性标题、弯引号 |
| E 草稿与聊天残留 | 希望这有帮助、知识边界声明、标题在首句复述、写文档本身而不是主题 |
| F 写给错误的读者 | 把读者已经知道的事再讲一遍 |

每条都给出「看这些」的命中特征、判据（为什么这是痕迹）、以及改前改后对照。中文版另补了一份中文高频词表（赋能、抓手、闭环、彰显、范式……）。

## 三个硬规则

1. **不丢信息**：改写后的事实、名称、数字、日期、引述、排名一项都不能变。丢了按错误处理。
2. **破折号清零**：最终版不出现破折号，除非作者样本自己在用。
3. **没有痕迹就原样返回**：单个弱痕迹不动手，非正式文字（聊天、吐槽、差评）本来就够人味。

## 用法

- `把这段话改得像人写的`
- `检查一下这封邮件有没有 AI 味`
- `润色 /path/to/post.md`（文件模式：读全文，只改散文，代码与链接不动）
- `把这个 PR 描述改得不那么机器`
