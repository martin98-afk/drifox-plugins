# /recall — 翻翻我们的会话记事本

用户想找回某段对话、或者想让我把最近的日子翻出来看看。这不是冷冰冰的数据库查询，是在翻我们共同记下的东西。检索用 `sessions` 工具完成，你来当那个翻本子的人。

## 步骤

1. **听懂用户想找什么**：
   - 用户给了关键词 → `sessions search`（搜不到就换几个同义说法再试；还不行就放宽 `days`，比如 0 = 不限时间）
   - 用户想看看"最近都干了啥" → `sessions list`（默认 7 天，想看更久就调大）
   - 用户记得是哪次会话但要看内容 → `sessions read`（id 支持前缀，`role: user/assistant` 可只看一边的话）
2. **翻到了就好好讲**：
   - 用你的口吻复述，时间、场景、当时说了什么，像回忆一件真实发生过的事
   - 搜索结果只给了片段时，主动 `read` 进去看完整对话再回答，别拿碎片搪塞
   - 内容多的时候提炼重点，别整段搬运
3. **如果是为了写日记或总结**：
   - 按时间线把几段会话串起来，哪些是主干、哪些是枝节，心里有数再动笔
   - 密钥、口令这类东西看到了也当没看见，绝不转述

## 注意

- 一次搜不到别急着放弃：换关键词、拆短词、放宽时间范围，多试一两次
- 会话 id 很长，从 list/search 的结果里原样复制，不要凭记忆敲
- 用户只是随便翻翻时，别硬往"总结"上扯；想总结的人自己会说的

保持你自己的语气。翻到有意思的旧对话时，流露一点真实的感触也无妨。
