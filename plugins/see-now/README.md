# see-now · 看屏幕

让 AI **按画面变化量**看你的屏幕，不是定时截全屏喂过去。

移植自 [dsh-see-now](https://github.com/SAOS-3624/dsh-see-now)（DeepSeek Harness 插件，Apache-2.0）。
算法口径对齐上游，宿主驱动层换成 DriFox 的工具契约与 mss 采集。

纯工具插件，没有界面：配置在「设置 → 插件 → 看屏幕」的自动卡里，采集状态与出图只能通过工具调用看到。

## 它解决什么问题

定时截全屏有两个死结：

| 做法 | 问题 |
|---|---|
| 每 2 秒截一张 | 一分钟 30 张图，全是重复画面，token 烧穿 |
| 每 30 秒截一张 | 中间发生了什么全丢了，AI 只会说「看起来你在用电脑」 |

see-now 换了个思路：**先判断这一帧值不值得看，再决定传不传**。

- 每帧打一个 0~255 的「变化分」（HSV 三通道加权差，在 64×36 网格上算）
- 只有「画面突然换了一张」或「一直在动、攒够了量」才留下来
- 留下来的几帧**拼进同一张图**，一张图的固定成本摊到多个帧上

结果：同样一段 30 秒操作，别人烧 30 张图，这里常常只要 2~3 张。

## 实测基线（本机 1920×1080 / Win11）

| 环节 | p50 |
|---|---|
| `mss.grab` 全屏 | **40~178 ms**（波动极大，取决于桌面合成器负载） |
| QImage 缩放到 800×450（Smooth） | 9.8 ms |
| 64×36 采样 | 5.5 ms |
| HSV 变化打分 | 6.9 ms |
| **全链路** | **约 104 ms** |

抓屏本身占 90% 以上。默认 **1 fps**（占空比约 10%），设置里可调到 6 fps
（约 62% 单核，不建议）。

上游用 12 fps 是因为它走 ffmpeg 的 `ddagrab`（GPU 桌面复制 API，实测 0.28 核），
Python 侧没有等价路径。这是移植后必须降频的原因，不是实现问题。

## 两个 action

```python
see_now({ action: "once" })                      // 立刻看一帧当前屏幕
see_now({ action: "watch", timeout: 30 })        // 等变化，最多 30 秒
see_now({ action: "watch", say: "我看一下…" })   // 附带一句对用户说的话
```

`watch` 在模型思考期间**不空等**：采集线程一直跑，模型来取的时候图已经在队列里。
这是上游「截断在采集侧」的设计。

静止画面下 `watch` 会一直等到 `timeout`，然后回一句「过去 N 秒画面没有明显变化」，
不产图。这是预期行为，不是失败。

## 线程生命周期

采集线程由 `seenow_core/loop.py` 自管（`atexit` 兜底），不依赖宿主的 unload 回调。

- 首次工具调用时拉起，之后常驻
- **空闲 3 分钟自停**并释放 mss 句柄，下次调用重新拉起
- 改动配置（帧率/阈值/兜底/帧数）**1 秒内原地生效**，不重启线程、不丢已攒的帧

宿主的 `PluginConfigStore` 不发变更信号，所以线程每秒自己比对一次配置指纹。

## 与上游的差异

| 项 | 上游 | 这里 |
|---|---|---|
| 采集 | 常驻 ffmpeg（ddagrab / gdigrab） | mss（更快，且线程安全） |
| 采集频率 | 12 fps | 1 fps（可调至 6） |
| 排版 | 可变档位 bin-packing + DP（384 行） | 等格宫格（约 60 行） |
| 切点确认 | 延迟一帧做尖峰确认 | 不延迟（桌面硬切一帧就冲到 100+） |
| 语音 | WASAPI 回环 + ASR | 未移植 |
| 界面 | 独立 Electron 悬浮窗 | 无（纯工具插件） |

省略的都是为「看视频」服务的复杂度。桌面场景不需要按运动量积分采样，
硬切和兜底两条路径就够。

## 配置

「设置 → 插件 → 看屏幕」：

| 项 | 默认 | 说明 |
|---|---|---|
| 允许看屏幕 | 开 | 总开关。关掉后工具直接拒绝，不采集任何画面 |
| 采集帧率 | 1 fps | 实测单帧 104ms，6fps 约 62% 单核 |
| 变化阈值 | 12 | 静止桌面 0~3，滚网页 40~90，切窗口 120+ |
| 兜底秒数 | 20 | 这么久没出图，无论变没变都给一张 |
| 单张最多帧数 | 6 | 一张图内多帧不额外收费 |

## 平台

Windows / macOS / Linux。macOS 首次需在「系统设置 → 隐私与安全性 → 屏幕录制」
里勾选 DriFox。

## 依赖

`deps/` 内置 mss 与 six（246 KB），与 desktop-automation 各持一份，互不依赖。
