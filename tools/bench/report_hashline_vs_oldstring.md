# hashline vs oldString 编辑基准报告

## 测试集分布

| 类别 | 用例数 | 说明 |
|---|---|---|
| 单行小替换 | 12 | 行内容 <20 字符，行尾追加标记 |
| 单行长替换 | 12 | 行内容 >80 字符，整行替换 |
| 多行替换 | 15 | 连续 2-5 行替换 |
| 大段替换 | 10 | 连续 >5 行替换 |
| 含特殊空白 | 10 | tab / 连续空格 / 行尾空格行 |
| CRLF 行尾 | 10 | 行尾 \r\n 文件 |
| 重复行 | 10 | 两处相同内容，目标为第一处（oldString 歧义） |
| **合计** | **79** | 1-4 类从真实代码文件提取，5-7 类合成 |

## 噪声配置与 token 口径

- 噪声概率：oldString `0.15`（多余空白/缺失换行/缩进/大小写/字符误抄）；anchor `0.05`（hash 字符/行号误抄）
- 重试上限 `3` 次；每用例蒙特卡洛 `10` 次；seed `42`
- token 口径：1 token ≈ 4 字符（OpenAI 经验值，ASCII 代码）；模型输出=edit 参数 JSON；回传=成功 unified_diff（hashline 另含 anchors 块）/失败错误消息（hashline 含重读 read 输出）

## 总体对比

| 指标 | oldString | hashline | 差异 |
|---|---|---|---|
| 首次成功率 | 67.6% | 94.4% | +26.8 pp |
| 最终成功率 | 76.1% | 100.0% | +23.9 pp |
| 平均尝试次数 | 1.57 | 1.06 | -0.51 |
| 平均总 token | 154 | 272 | +76.6%（hashline 多 118 token） |

## token 节省（hashline vs oldString，按类别）

| 类别 | oldString token | hashline token | 节省幅度 |
|---|---|---|---|
| 单行小替换 | 138 | 359 | -159.5% |
| 单行长替换 | 195 | 445 | -128.3% |
| 多行替换 | 188 | 281 | -49.2% |
| 大段替换 | 216 | 484 | -123.9% |
| 含特殊空白 | 64 | 83 | -30.1% |
| CRLF 行尾 | 66 | 91 | -37.7% |
| 重复行 | 189 | 105 | +44.1% |

## 结论

- 成功率：首次 94.4% vs 67.6%（hashline 高 26.8 pp）；最终 100.0% vs 76.1%
- token：hashline 平均 272 vs oldString 154，总体 多出 118 token（-76.6%）
- 收益最大：重复行（节省 44.1%）
- 收益最小/无收益：单行小替换（多出 220 token）

python tools/bench/bench_hashline_vs_oldstring.py --seed 42 --runs 10 --noise-old 0.15 --noise-anchor 0.05
